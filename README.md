# manualAI.org

Repository for the independent browser apps published under the manualAI.org umbrella.

## Apps on the launch page

| App | Path | Purpose | Entry point |
|---|---|---|---|
| **pwnd** | [`pwnd/`](pwnd/) | Quiz battle and pond-game prototype | [`/pwnd/`](https://app.manualai.org/pwnd/) |
| **MyDog** | [`mydog/`](mydog/) | Personality test and dog-breed profiles | [`/mydog/`](https://app.manualai.org/mydog/) |
| **MyCat** | [`mycat/`](mycat/) | Personality test and cat-breed profiles | [`/mycat/`](https://app.manualai.org/mycat/) |

The root [`index.html`](index.html) is the app-selection page. The individual apps have separate code, styles, data, documentation, and tests; Vercel routing and shared API helpers remain at the repository root.

## MyCat

- App: [`mycat/index.html`](mycat/index.html)
- Research-backed catalogue source: [`mycat/breed-research.json`](mycat/breed-research.json)
- Browser data: [`mycat/data.js`](mycat/data.js), generated by `python3 mycat/tools/build-data.py`
- Photos: 18 profiles, six locally served WebP images each under `mycat/images/v1/`
- Photo provenance: [`mycat/photo-sources.json`](mycat/photo-sources.json); regenerate the HTML credit page with `python3 mycat/tools/build-attribution.py`
- Tests: `npm run test:mycat:beta`, `npm run test:mycat:images`, and `npm run test:mycat:legal`

MyCat is a standalone cat-profile discovery app, **not a dating app**. Its 30-question personality questionnaire and playful rank ordering run in the browser; answers are not sent to an evaluation API. The scoring for breed profiles is heuristic, not a validated psychological, veterinary, or behavioural assessment. Breed tendencies cannot predict an individual cat's personality. Every profile includes a source link and a health/welfare caveat; medical questions should go to a veterinary practice.

Each Commons photo is locally resized to WebP, and its source, creator and license are recorded in the attribution page. The service worker stores app files for offline fallback and bounds the local photo cache.

## Fish Royale

[`fishroyale/`](fishroyale/) is a standalone six-round browser arena. Three fixed quiz paths feed a deterministic tactics engine; the opponent's lane, attack, and guards are public before each move. All four cards are available from the start, and the same choices always resolve the same way. It has no accounts, purchases, paid evolutions, loot, random card draws, timers, streaks, daily rewards, leaderboard, or saved progression. Run `npm run test:fishroyale` for its engine and fair-play tests.

## cats&dogs prototype

`/catsdogs/` remains directly reachable as an **unlisted, separate prototype**; it has been removed from the launch-page card row. Its eventual paired cat/dog dating concept is not implemented by MyCat: the currently separate apps are `/mydog/` and `/mycat/`. The prototype still uses its own gender/preference onboarding and feedback flow and must not be confused with either single-species profile app.

## Shared root infrastructure

- `index.html` — app-selection shell
- `vercel.json` — deployment routes and security headers
- `api/` — shared serverless API handlers
- `package.json` — repository scripts and dependencies

Keep app-specific files under their app directory (`pwnd/`, `fishroyale/`, `mydog/`, `mycat/`, or `catsdogs/`). The repository's standard `npm test` command remains limited to its existing fast engine/smoke suites; the MyCat browser and legal suites are run using their explicit commands above.
