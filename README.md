## MyCat

- App: [`mycat/index.html`](mycat/index.html)
- Research-backed catalogue source: [`mycat/breed-research.json`](mycat/breed-research.json)
- Browser data: [`mycat/data.js`](mycat/data.js), generated by `python3 mycat/tools/build-data.py`
- Photos: 18 profiles, six locally served WebP images each under `mycat/images/v1/`
- Photo provenance: [`mycat/photo-sources.json`](mycat/photo-sources.json); regenerate the HTML credit page with `python3 mycat/tools/build-attribution.py`
- Tests: `npm run test:mycat:beta`, `npm run test:mycat:images`, `npm run test:mycat:legal`, and `npm run test:mycat:dating`

MyCat is a standalone cat-profile discovery app, **not itself a dating app**. Its 30-question personality questionnaire and playful rank ordering run in the browser; answers are not sent to an evaluation API. The scoring for breed profiles is heuristic, not a validated psychological, veterinary, or behavioural assessment. Breed tendencies cannot predict an individual cat's personality. Every profile includes a source link and a health/welfare caveat; medical questions should go to a veterinary practice.

Each Commons photo is locally resized to WebP, and its source, creator and license are recorded in the attribution page. The service worker stores app files for offline fallback and bounds the local photo cache.

## MyCat × MyDog dating-profile MVP

- Route: [`mycat/cats&dogs/`](mycat/cats&dogs/) — [`/mycat/cats&dogs/`](https://app.manualai.org/mycat/cats%26dogs/)
- Passwordless email sign-in; profile data is stored in the separate Supabase table `mycat_dating_profiles`.
- The six-choice genotype field (`XX`, `XY`, `X0`, `XXY`, `XYY`, `XXX`) is private, saved only after explicit consent, and protected by owner-only row-level security.
- MyCat-result transfer is optional and separately consented. Only profile IDs, score summary and Big Five summary are eligible; individual questionnaire answers and favorites are never uploaded.
- Matching, ranking and genotype-based rules are **not active**. Rules will be added separately after they are specified.
- Schema: [`supabase/migrations/20261004165352_create_mycat_dating_profiles.sql`](supabase/migrations/20261004165352_create_mycat_dating_profiles.sql)
- Privacy notice: [`mycat/cats&dogs/privacy.html`](mycat/cats&dogs/privacy.html)

## Fish Royale

[`fishroyale/`](fishroyale/) is a standalone six-round browser arena. Three fixed quiz paths feed a deterministic tactics engine; the opponent's lane, attack, and guards are public before each move. All four cards are available from the start, and the same choices always resolve the same way. It has no accounts, purchases, paid evolutions, loot, random card draws, timers, streaks, daily rewards, leaderboard, or saved progression. Run `npm run test:fishroyale` for its engine and fair-play tests.

## cats&dogs prototype

`/catsdogs/` remains directly reachable as an **unlisted, separate legacy prototype** and is not the new MyCat × MyDog profile app. The current private onboarding is at `/mycat/cats&dogs/`; it stores profile data only and does not yet run matching. The prototype retains its own separate onboarding and feedback flow and must not be confused with either the single-species profile apps or the new dating-profile MVP.

## Shared root infrastructure

- `index.html` — app-selection shell
- `vercel.json` — deployment routes and security headers
- `api/` — shared serverless API handlers
- `package.json` — repository scripts and dependencies

Keep app-specific files under their app directory (`pwnd/`, `fishroyale/`, `mydog/`, `mycat/`, or `catsdogs/`). The repository's standard `npm test` command remains limited to its existing fast engine/smoke suites; the MyCat browser, dating and legal suites are run using their explicit commands above.
